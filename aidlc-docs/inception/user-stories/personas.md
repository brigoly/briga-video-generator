# Personas

## Persona P1: Solo Video Creator

### Profile
- **Role**: Independent content creator
- **Primary Goal**: Turn a high-level topic into publish-ready short videos quickly across multiple platforms
- **Primary Channels**: TikTok, YouTube Shorts, Instagram Reels
- **Working Style**: CLI-first, automation-driven, low tolerance for repetitive manual work

### Needs
- End-to-end automation from topic input to export package
- Consistent output quality and style controls
- Clear stage-by-stage progress visibility
- Fast reruns with predictable behavior
- Reliable handling of failures with retry support

### Pain Points
- Time spent manually adapting content per platform
- Inconsistent quality across generated outputs
- Fragile pipelines that fail late and require full restarts
- Difficulty balancing cost with content volume

### Success Criteria
- Receives complete manual-upload-ready packages for all target platforms
- Achieves high end-to-end completion rate per run
- Can regenerate variants with minimal reconfiguration effort
